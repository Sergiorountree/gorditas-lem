🔑 Contraseñas de Acceso

Las contraseñas de los gerentes y administrador ahora se gestionan directamente en Firebase Authentication.

Para cambiar una contraseña o crear un nuevo usuario:

  1. Entra a console.firebase.google.com
  2. Selecciona el proyecto gorditas-grupolem
  3. Ve a Authentication → Users
  4. Click en los 3 puntos (⋮) del usuario → Restablecer contraseña o crea uno nuevo

🏪 Nueva Sucursal

⚠️ Después de agregar la sucursal aquí, también debes crear el usuario en Firebase Authentication y avisarme para actualizar el código con el nuevo correo.
